# kerf-site

The website of Kerf, served by GitHub Pages at https://kerf.site.

- `docs/` — product documentation (setup, importing AI/HTML designs, editing in the Block Editor, menus & links, design updates, inner pages, live posts, forms & site details, Kerf AI, Client Mode, and licensing).
- `blog/` — articles, workflows, prompt briefs, topic tag archives, and `rss.xml`.
- `demo/` — the live demo: `blueprint.json` (what WordPress Playground sets up), `kerf-demo.zip` (Kerf, built by `tools/demo/build-demo.php` in the Kerf repository; it runs only in Playground) and `copperline-studio.zip` (a sample design to import).
- `sitemap.xml` — XML sitemap for search engines.
- `CNAME` — the custom domain.
