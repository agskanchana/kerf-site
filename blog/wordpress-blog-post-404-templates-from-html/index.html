AI Tools Make a Home Page. Your WordPress Site Also Needs a Blog, Single Post, Search and 404

Oct 29, 2026 Kerf Team 5 min read

Ask an AI tool for a website and you usually get a home page, maybe an about page and a contact page. A WordPress site needs more than that, and the pages it needs are the ones nobody drew: the ones that appear the first time someone searches, follows a category link or mistypes an address.

The Six Pages Every WordPress Site Needs

  • Blog: the list of posts.
  • Single Post: one article.
  • Page: the standard page template.
  • Archive: category and date archives.
  • Search: the results page.
  • 404: the page for an address that does not exist.

If those are missing, WordPress falls back to whatever the theme provides, and the result looks like a different website attached to yours.

What Kerf Does Without Being Asked

Right after an import, Kerf loads your new home page in a hidden frame and measures what it actually looks like: its computed typography, heading hierarchy, background and text colours, border radius and container width. Any template your ZIP did not include is wrapped in your imported header and footer and styled with those measured values. A blog index that nobody designed still sits in the same container, in the same type, under the same menu. Read the inner pages documentation →

Bring Your Own Templates

If you have HTML files for any of those pages, include them in the ZIP. Kerf recognises blog.html, post.html (or single.html), page.html, archive.html, search.html and 404.html during the pre-import check and turns them into live block templates, which are the templates the WordPress Site Editor uses. Your own markup and classes stay as written, around the live post data.

Fine-Tune Them Under Kerf → Inner pages

Open Kerf → Inner pages to see each page type live inside the admin screen. You can adjust the background, surface, text and accent colours and the typography tokens that were measured from your home page, and switch any template between its imported custom layout and the measured default whenever you like.

Ask Your AI Tool for the Missing Ones

For any template your ZIP lacks, the Design your own tab in Kerf → Inner pages lists what is missing and writes a ready-to-copy prompt. It carries your design’s exact CSS class names, the header and footer context, and the data-kerf-* markers that bind a template to live WordPress data. Paste it into Claude, ChatGPT or Gemini, add the files it returns to your ZIP, and import again.
