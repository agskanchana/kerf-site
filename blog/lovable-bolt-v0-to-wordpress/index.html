Lovable, Bolt or v0 Site to WordPress? An Honest Guide to What Works Today

Oct 23, 2026 Kerf Team 5 min read

We make Kerf, a WordPress theme that imports websites made by AI tools. One question comes up again and again: “I built my site with Lovable (or Bolt, or v0). Can I put it on WordPress?”

The honest answer is: not by importing it—not with Kerf, and not with any tool that works from HTML. Here’s why, and what you can do instead.

Why a React App Is Different from an HTML Website

Tools like ChatGPT, Claude, Gemini and Google Stitch can give you HTML files: open index.html and the whole page is there—every heading, paragraph and picture written out in the file.

Lovable, Bolt and v0 typically build React apps. Their source is components and a package.json; a build step bundles it into JavaScript, and the page is assembled in the visitor’s browser when that JavaScript runs. Open the built index.html and you’ll mostly find an empty container like <div id="root"></div>.

An HTML importer turns the elements in the HTML into editable blocks. When the elements only exist after a script builds them, there is nothing in the file to turn into blocks. That’s why Kerf doesn’t import these apps yet—and why its pre-import check tells you so before anything changes on your site.

Your Real Options

1. Keep the App Where It Is, and Add WordPress Next to It

If the site is mostly an app—logins, dashboards, live data—keep hosting it where it runs well today (for example Netlify or Vercel). If you also want a blog or editable marketing pages, run WordPress alongside it, for example on a subdomain, and link between the two.

2. Use WordPress as the Content Source (Headless)

A developer can keep the React front end and have it fetch posts and pages from WordPress’s REST API. Editors write in WordPress; the app shows the content. It’s flexible, but it is a development project, not a one-click move, and the WordPress block editor won’t show your app’s design while you edit.

3. Rebuild the Pages in WordPress

For a simple marketing site, rebuilding by hand in a page builder or block theme works. It takes time, and the result is a look-alike rather than the same design.

4. Recreate the Design as Plain HTML, Then Import It

If what you love is the look, not the app logic, you can ask an AI tool to recreate the pages as plain HTML, CSS and JavaScript—no React, no build step. That version is a normal website, and an HTML website can be imported into WordPress as editable blocks. Our prompt brief for WordPress-ready AI HTML lists what to ask for.

How to Tell Which Kind You Have

If your project has a package.json and you need to run something like npm run build to see it, it’s an app. If you can double-click index.html and see the full page with its words in the file, it’s HTML—and that’s the kind Kerf imports.

What Kerf Is For

Kerf is built for HTML websites: the ZIP you get from ChatGPT, Claude, Gemini or Google Stitch, or from a designer. It keeps the same tags, classes, stylesheets and scripts, and makes every word, picture and menu editable in WordPress. If that’s what you have, you can try it free in your browser—a private WordPress with Kerf installed, no sign-up.
