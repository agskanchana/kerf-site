Installation & licence setup

Install the Kerf WordPress theme, activate your Freemius lifetime licence key, and verify your environment.

Kerf ships as a single, self-contained WordPress block theme (kerf-<version>.zip) with the conversion engine, block library, and all Pro and AI tools built right inside. There are no separate companion plugins to install or keep in sync.

Requirements

  • WordPress 6.9 or newer (tested up to WordPress 7.1+; uses modern Block Bindings and Full Site Editing APIs).
  • PHP 8.0 or newer (PHP 8.2 or 8.3 recommended) with the standard DOM / libxml extension enabled.
  • Administrator account with unfiltered_html capability: On a standard single-site WordPress installation, every Administrator has this automatically. On WordPress Multisite, importing designs requires a Super Admin because HTML designs carry stylesheets and scripts.

1. Install the Kerf theme

  1. After purchasing Kerf on kerf.site, open your receipt email from Freemius and download kerf-<version>.zip.
  2. In your WordPress admin dashboard, go to Appearance → Themes → Add New Theme → Upload Theme.
  3. Choose the downloaded kerf-<version>.zip file and click Install Now.
  4. Click Activate.

One Product, Every Feature

Every plan (Personal, Freelancer, and Agency) includes the exact same theme ZIP with every feature unlocked. Plans only differ by the number of sites you can activate.

2. Activate your licence key

  1. Once Kerf is active, click the new Kerf item in your WordPress admin sidebar.
  2. Paste the licence key from your Freemius email into the activation prompt and click Activate License.
  3. Once activated, the full Kerf menu appears in your sidebar: Dashboard, Import design, Build with AI, Make a page, Update design, Inner pages, Links, Site details, Form entries, Settings, and Account.

Migrating from older Kerf plugins

If an earlier beta site ran the standalone Kerf Blocks and Kerf Pro plugins, simply upload and activate the current kerf theme ZIP under Appearance → Themes. Kerf will display an admin notice asking you to deactivate and delete the old plugins under Plugins. All of your imported pages, staged assets, menus, and settings remain intact.
